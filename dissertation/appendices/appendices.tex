\chapter{Supplementary Experimental Results}

\section{Clothing-range coverage in the retained FITB subset}

The retained official FITB subset contained 46 menswear-labelled questions and
4,422 womenswear-labelled questions. Descriptive accuracy was 0.4348 for the
menswear subset and 0.6043 for the womenswear subset. The menswear result is not
treated as a reliable group comparison because its sample is substantially
smaller.

\chapter{Data Sources and Reproducibility}
\label{app:reproducibility}

This appendix provides direct links to the external resources used in the
project. The research method, dataset preparation and evaluation procedure are
described in Chapters 3 and 4.

\begin{itemize}
  \item \textbf{Polyvore Outfits disjoint dataset:}
  \href{https://github.com/mvasil/fashion-compatibility}{authors' code and dataset repository}
  \parencite{vasileva2018repository}. This was the main source for compatibility
  training and evaluation.
  \item \textbf{Maryland Polyvore metadata:}
  \href{https://github.com/xthan/polyvore-dataset}{dataset repository}. This
  supplied supporting product-category metadata.
  \item \textbf{Zara Products:}
  \href{https://www.kaggle.com/datasets/maparla/zara-products}{Kaggle dataset page}
  \parencite{parrenolara2024zara}. This was used for recognition preparation
  and the feature-domain comparison reported in the dissertation.
  \item \textbf{SigLIP:}
  \href{https://huggingface.co/google/siglip-base-patch16-224}{model card and checkpoint page}
  \parencite{google2024siglipmodelcard}. The encoder was used in frozen form.
  \item \textbf{Open-Meteo:}
  \href{https://open-meteo.com/en/docs}{forecast API documentation}
  \parencite{openmeteo2026}. This supplied the weather context used by the
  prototype.
\end{itemize}

The project repository contains the code, tests and machine-readable result
files used to record the experiments. Key model settings, sample sizes,
confidence-interval procedures and limitations are reported in the main
chapters so that the findings can be interpreted without relying on this
appendix.
