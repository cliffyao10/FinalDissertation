# AI Outfit Recommendation Prototype

This project is a lightweight AI outfit recommendation prototype for a dissertation project.

The system allows users to upload a clothing image. It then identifies the clothing category and main colour, and generates simple outfit recommendations.

## Project Structure

- `app.py`: Streamlit web interface
- `src/recognition.py`: clothing category recognition module
- `src/colour_detection.py`: colour detection module
- `src/recommendation.py`: outfit recommendation module
- `data/catalogue.csv`: product catalogue data
- `results/screenshots/`: screenshots for dissertation evidence

## Current Version
